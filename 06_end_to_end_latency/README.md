# 06 — End-to-end latency

The assessment requires camera-to-actuator latency over 20+ real events. The included simulator measures software event-path timing only. It does not include camera exposure, frame acquisition, model inference on the target, GPIO/relay switching, or physical actuator travel.

For final proof, timestamp frame acquisition and confirmed actuator feedback for at least 20 events. Report median, p95, min/max and the measurement method.
